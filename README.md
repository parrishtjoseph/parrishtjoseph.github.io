# Joseph Parrish — Official Website

Static website for GitHub Pages.

## Publish from GitHub

1. Open the `parrishtjoseph.github.io` repository.
2. Choose **Add file → Upload files**.
3. Upload every file and folder from this package, keeping the folder structure intact.
4. Commit the upload to the `main` branch.
5. Open **Settings → Pages**.
6. Under **Build and deployment**, select **Deploy from a branch**.
7. Choose `main` and `/ (root)`, then save.
8. The site should appear at `https://parrishtjoseph.github.io` after GitHub finishes deployment.

Do not change GoDaddy or Wix yet. Connect the custom domain only after this preview has been reviewed.
